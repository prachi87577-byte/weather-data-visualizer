# weather-data-visualizer
📜 Report Summary (climate_report.txt)
🌍 Introduction
This project analyzes synthetic daily weather data for Sohna, Haryana to support climate awareness and sustainability planning.
🧹 Data Cleaning
- Handled missing values using forward fill
- Converted date column to datetime format
- Selected relevant columns: temperature, rainfall, humidity
📊 Statistical Analysis
- Daily mean temperature: ~25.5 °C
- Monthly rainfall peak: July (~180 mm)
- Seasonal trends: Summer hottest, Monsoon wettest
📈 Visualizations
- Line chart shows temperature fluctuations across the year
- Bar chart highlights rainfall concentration in monsoon months
- Scatter plot reveals comfort zones around 25 °C and 60% humidity
- Combined plot shows cooling effect of rainfall on temperature
📂 Grouping & Aggregation
- Grouped by month and season to compute average temperature and total rainfall
- Seasonal comparison shows clear climate patterns useful for campus planning
✅ Conclusion
- Data-driven insights support climate awareness
- Findings can guide campus sustainability initiatives
- Next steps: Extend analysis to renewable energy and resource usage
